ROCKET POCKET

A tiny 3D car-soccer arena. Play on mobile or desktop, solo or with friends.
Controls — Mobile: left stick to steer/drive; boost, jump, brake on right. Desktop: WASD/arrows, Space jump, Shift boost, S/reverse, R reset.
Multiplayer uses Firebase Realtime Database for room discovery/signaling and WebRTC data channels for live player state. Enable Anonymous sign-in in Firebase Authentication and set Realtime Database rules to require auth != null for /pocketArenaRooms. The included config is public client config, not a server secret. STUN-only peer connections may fail on restrictive networks. Original prototype; not affiliated with Rocket League.
